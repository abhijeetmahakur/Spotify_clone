# Browser Music Player Exercise

This repository contains a static HTML, CSS, and JavaScript music-player interface with local media and image assets. It is a front-end exercise, not an official Spotify client or a service connected to Spotify accounts.

## Run locally

Open `index.html` in a modern browser. If local file restrictions interfere with media playback, start a static server from this directory:

```bash
python -m http.server 8000
```

Then open <http://localhost:8000>.

## Tests

No build system or automated test suite is present. Test playback and controls manually in a browser.
